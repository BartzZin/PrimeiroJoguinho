# Origem dos ativos

- Seis miniaturas `.glb`: modelos originais gerados por `tools/generate_models.py` com Blender 4.5.3 LTS.
- Doze símbolos de cartas `.svg`: desenhos vetoriais originais de `tools/generate_card_icons.py`.
- Tabuleiro, materiais, interface e efeitos: código Godot do projeto.
- `Xadrez mágico em estilo anime.png`: referência fornecida pelo proprietário; não incorporada ao executável.
- Godot e avisos de terceiros: diretório `licenses/Godot`; incluir na distribuição Windows.

Fontes Blender atuais são procedurais em Python; ainda não há arquivos `.blend` a versionar. Ao incorporar `.blend`, configurar Git LFS antes do primeiro commit desses arquivos.
