The 1K and 4K HDR files are included in `client-godot/assets/arena/sky/`.
Original download URLs and verified MD5 checksums are recorded in
`art/arena/sky-source.json`. The game adapts the lower-hemisphere presentation
with its sky shader to create a cloud sea for the floating arena.
